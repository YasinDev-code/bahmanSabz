# Next Game

این پروژه یک نمونه اپلیکیشن Next.js (نسخه 16.1.6) با React 19.2.3 و Chakra UI v3 است که لیست بازی‌ها را از RAWG API دریافت و به‌صورت ریسپانسیو نمایش می‌دهد. قابلیت جستجو بر اساس نام و تگ‌ها، صفحه‌بندی ۱۰‌تایی و صفحه جزئیات هر بازی نیز پیاده‌سازی شده است.

## ویژگی‌ها
- جستجو بر اساس نام بازی و تگ‌ها
- صفحه‌بندی: هر صفحه ۱۰ بازی
- صفحه جزئیات بازی با تصویر، توضیحات، ژانرها، پلتفرم‌ها، تگ‌ها، متاکریتیک و تاریخ انتشار
- استایل یکپارچه و کارت‌مانند با Chakra UI (Center, Container, VStack, Table و Badge)
- Proxy داخلی برای RAWG API تا کلید API فقط سمت سرور استفاده شود

## پیش‌نیازها
- Node.js 20.x یا جدیدتر
- داشتن کلید RAWG API و قرار دادن آن در فایل محیطی

## راه‌اندازی
1. نصب وابستگی‌ها:
   ```bash
   npm install
   ```
2. ساخت فایل محیطی:
   - در ریشه پروژه `next-game` یک فایل `.env.local` بسازید و مقدار زیر را اضافه کنید:
     ```env
     gameKey=YOUR_RAWG_API_KEY
     ```
3. اجرای توسعه (با Webpack جهت جلوگیری از مشکلات Hydration):
   ```bash
   npm run dev
   ```
   سپس مرورگر را روی `http://localhost:3000` (یا پورتی که لاگ نشان می‌دهد) باز کنید.

## ساختار پوشه‌ها
- `app/page.tsx`: صفحه اصلی؛ شامل هدر جستجو و نمایش لیست بازی‌ها
- `app/components/GameHeader.tsx`: هدر جستجو با فیلدهای نام و تگ‌ها
- `app/components/GameFetcher.tsx`: دریافت داده‌ها از API داخلی با صفحه‌بندی
- `app/components/GameList.tsx`: جدول نمایش بازی‌ها و ناوبری به جزئیات
- `app/games/[id]/page.tsx`: صفحه جزئیات داینامیک برای هر بازی
- `app/api/games/route.ts`: مسیر داخلی برای لیست بازی‌ها (Proxy به RAWG)
- `app/api/games/[id]/route.ts`: مسیر داخلی برای جزئیات بازی (Proxy به RAWG)
- `app/types/game.ts`: تایپ‌های ساده‌شده برای لیست و جزئیات بازی

## نکات فنی
- Chakra UI با Provider در `app/layout.tsx` راه‌اندازی شده و با React 19 سازگار است.
- برای جلوگیری از Hydration Errorهای مربوط به Emotion در حالت Turbopack، اسکریپت‌های `dev` و `build` با `--webpack` تنظیم شده‌اند.
- بهینه‌سازی واردکردن پکیج‌ها با `optimizePackageImports` فعال شده است تا فقط کامپوننت‌های مورد استفاده از Chakra لود شوند.
